# Правила проекта для агента (Freebuff)

## Кто что делает

- **Аудит, проверки, безопасность, мониторинг — работа Freebuff (агента).** Их выполняют
  скрипты в `agent-health/` и команды, которые запускает агент.
- **ИИ-модели в чате (CLAUDE / GEMINI / DEEPSEEK / ChatGPT) ничего не аудируют и не
  защищают.** Они решают школьные задания и только. Нельзя добавлять в
  `SCHOOL_SUBJECT_RULES`, `persona` или любой промпт просьбы «проведи аудит»,
  «защити систему», «проверь безопасность»: модель — объект проверки, а не проверяющий.
- Слово «ты» в задачах пользователя относится к Freebuff, а не к моделям.

## Что проверяет аудит

`agent-health/audit.ps1` — контракт API и гигиена репозитория без трат квоты моделей:

```sh
powershell -NoProfile -ExecutionPolicy Bypass -File agent-health/audit.ps1
```

- страница отвечает 200 и содержит `#root`;
- `/api/chat` отвергает GET (405), битый JSON (400), пустой запрос (400), пустой список моделей (400);
- обработчик помечает ответы `no-store`;
- в отслеживаемых git файлах нет ключей, `.env` не в индексе и попадает под `.gitignore`.

Флаг `-Deep` добавляет один живой запрос к модели — это тоже запускает агент, модель
здесь только наблюдается. Лог: `agent-health/logs/YYYY-MM-DD.log`, код возврата 1 при провалах.

## Ограничения скриптов

`agent-health/audit.ps1` держим в ASCII: Windows PowerShell 5.1 читает UTF-8 без BOM как
ANSI, и кириллица ломает разбор (многобайтовый символ превращается в кавычку).
